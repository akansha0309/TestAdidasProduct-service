**ReadMe for API tests for Adidas Product-service**



 
 
**How to invoke tests:**

1- Compile the project using **mvn comile** then Run command **mvn test** for this project

2- Import the project to any Java IDE like Eclipse. **‘Run As’ -> TestNG Suite.**


**TechStack:**
TestNG, RestAssured


**Test Report:**

Navigate to **test-output>index.html**

**Logs:**

Navigate to **application.log**

**Test Report:**

Navigate to **src/test/resources/testng.xml**
